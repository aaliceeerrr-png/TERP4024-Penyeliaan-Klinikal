Panduan Penggunaan

GitHub Pages memaparkan portal; Google Apps Script diperlukan untuk menerima respons ke Google Sheets.

Tetapan Penyimpanan Google Sheets

Setelah menerbitkan fail Code.gs sebagai Apps Script Web App, masukkan URL berakhir dengan /exec di bawah. Alamat ini disimpan pada pelayar ini sahaja dan tidak dihantar ke GitHub.

Perhatian: Tetapan ini bukan log masuk atau perlindungan data. Portal GitHub Pages adalah laman awam. Untuk respons sulit, gunakan kawalan akses Google yang sesuai atau Google Forms berhad akses. Jangan muat naik data murid atau respons peribadi ke repository GitHub.

Langkah penggunaan
