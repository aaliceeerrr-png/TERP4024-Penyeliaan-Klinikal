A. Butiran Pemerhatian

Skala panduan: 1 = sangat terhad, 2 = kurang berkesan, 3 = sederhana, 4 = baik, 5 = sangat baik, TD = tidak dapat diperhatikan. Skala ini bukan markah rasmi PR1.

Panduan Penggunaan

Portal ini digunakan untuk mengisi, mencetak dan menyimpan salinan PDF. Tiada sambungan Google Sheets atau penghantaran dalam talian.

Langkah penggunaan

  1. Lengkapkan Borang Pra Penyeliaan berdasarkan perbincangan sebenar.
  2. Tekan Cetak untuk mencetak borang atau Simpan PDF dan pilih Save as PDF dalam dialog pelayar.
  3. Simpan fail PDF pada komputer atau Google Drive peribadi yang mempunyai kawalan akses sesuai.
  4. Buka tab Pemerhatian untuk melengkapkan instrumen pemerhatian; cetak atau simpan PDF secara berasingan.
Penting: Jawapan tidak disimpan secara automatik. Simpan PDF sebelum menutup, memuat semula atau meninggalkan halaman. Jangan gunakan repository GitHub awam untuk menyimpan maklumat sulit.
